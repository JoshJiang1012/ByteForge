# ByteForge 6.2 — Tutor Layout Recovery

6.2 replaces the failed 6.1 tutor layout strategy.

## Fixed
- Lyra now decorates only the mentor header; lesson content no longer shares horizontal width with character art.
- Every syntax/tutor accordion is full-width.
- Code blocks preserve indentation and use horizontal scrolling instead of being clipped.
- Symbol breakdown rows collapse to one column when narrow.
- At narrow page widths the entire mentor rail becomes a single-column section below the editor.
- Removed conflicting left-margin behavior from all tutor cards.

No quest logic or Judge behavior changed.
